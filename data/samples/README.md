# Example files (for local testing only)

These files are **made up**. They are not Freshroots data and must never be uploaded to the live site.

| File | What it is for |
|---|---|
| `open_purchase_orders.example.csv` | Try the open-PO feature on the Upload page. |
| `weekly_sales_W43-W46.example.csv` | Four invented weeks after the sample data (W43 to W46), so the Performance page has runs old enough to measure. Values are the last four weeks' average with small made-up ups and downs. |
| `sku_master_with_prices.example.csv` | The sample SKU master plus an invented `Unit_Price` column, to see the rupee exposure card. Prices are placeholders. |
